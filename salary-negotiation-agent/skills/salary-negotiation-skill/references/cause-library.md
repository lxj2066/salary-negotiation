# 由头库：什么理由能让公司掏钱，什么理由只会让你显得不懂事

由头（cause）是这次申请的**法律依据**。公司批钱不是因为你需要，是因为有一个它自己认的理由成立。选错由头，后面的话术再漂亮也白搭。

选由头的顺序不能反：**先定由头，再算钱。** 反过来会退化成讨价还价。

---

## 一、六类可用由头

### 1. 职责扩展 / 岗位价值重估（接受度最高，优先用）

**成立条件**：职责**层级**变了，不是工作量线性增加。

层级变化的四种信号：
- 从执行到统筹（自己干 → 带人干 → 定规则）
- 从单点到跨线（只管一条业务 → 管多条并做取舍）
- 从支持到参与决策（提供数据 → 参与定目标）
- 从内部到对外（只对内交付 → 直接面对客户/合作方）

**不成立的样子**：「事情变多了」「加班变多了」「一个人干三个人的活」——这些是工作量，工作量该配人手，不该配加薪。公司听到的是「你效率有问题」。

**必须做的动作**：写「入职时 vs 现在」两栏对比。左边写当初 JD 或口头约定，右边写现在实际在做的事。**至少要有两行是左边完全没有的。**

**最强的翻译**：把职责增量翻成「外部雇一个人要花多少」。话术：
> 「我现在的职责已经覆盖 A、B、C 三块，其中 B、C 是去年 Q3 之后接的。按现在的岗位描述招一个人，市场上大概是什么价位？如果拆成两个岗位，成本会更高。」

这句话的杀伤力在于：它不是在说「我要涨」，是在说「你现在花这个钱是便宜的」。

### 2. 职级带宽内校准（流程最容易受理）

**成立条件**：薪资低于当前职级带宽中位，且公司有宽带薪酬制度（外企、成熟民企常见）。

**关键**：这条**不涉及职级变动**，只做「带宽内位置修正」。所以它走的是校准流程，不是晋升流程，受理门槛低得多。

**话术**：
> 「我的职级没变，但薪资位置在带宽的偏低区间。想确认一下，这个位置是当初定级时的历史原因，还是我理解的定位有偏差？如果是历史原因，有没有校准的空间？」

注意最后一句给了对方台阶——「历史原因」是最好用的台阶，因为它不指向任何人的失误。

### 3. 增量贡献 / 超额产出（要求硬数据）

**成立条件**：有可量化、且**超出岗位基础要求**的结果。

**最容易搞错的一点**：达标 KPI 不算增量。完成本职不等于超额贡献。销售完成 100% 任务是本职，完成 140% 才是增量；运营把留存做到行业平均是本职，做到行业前 25% 才是增量。

**增量必须能被拆成钱**：收入增量 / 成本节省 / 效率折算（人天 × 单价）/ 风险规避（避免的损失 × 概率）。

**话术**：
> 「去年我负责的 A 线带来 X 万增量收入，这部分不在我岗位的基础目标里。按公司对超额部分的分享惯例，我想谈谈这块怎么体现。」

### 4. 关键人才保留 / 稀缺性（用经济账，不用威胁）

**成立条件**：替换成本高、交付依赖强。

**替换成本怎么估**（三个可查的项）：
- 招聘成本：年薪 15%—30%（含猎头费 20%—25%、面试时间成本）
- 上手期折损：3—6 个月产能不足
- 隐性成本：客户关系断档、项目延期、团队补位加班

公开人力资本研究常把总替换成本估为 **6—9 个月薪资**。这是区间估计，不是精确值，引用时说「通常估计」不说「一定是」。

**话术（经济账版本，不用威胁）**：
> 「我算过一笔账：我这个位置如果换人，招聘加上手期大概是 6 到 9 个月的成本，还不算客户关系重新建立。我不是在说要走，是说从成本角度看，把资源放在保留上更划算。」

**这条的红线**：一旦出现「所以你们得给我涨，不然我就走」，由头立刻失效，还倒扣分。经济账要说得像替公司算账，不像替自己开价。

### 5. 窗口内优先级争取（务实，适合没硬增量的人）

**成立条件**：没有刚性增量，也不在倾斜序列，但公司确实有调薪窗口和预算池。

**核心**：不争「我值多少」（争不过），争「排序」。因为预算池分配本质是排序问题，不是估值问题。

**话术**：
> 「我知道今年总量有限。我想了解的是，这个池子的分配是按什么顺序排的——是绩效等级、还是业务线优先级？如果按这个顺序我排在后面，我需要做到什么才能往前排？」

这句话的作用：把「给不给你」变成「按什么规则给」，而规则一旦说出口，就有了下一次的依据。

### 6. 市场对标 / 薪酬倒挂（只能作辅，不能主谈）

**成立条件**：有可靠的市场区间，或内部同岗新人薪资高于老人（倒挂）。

**为什么不能主谈**：一旦主由头是「外面给得多」，公司的最省力回应就是「那你出去看看」，或者「我们的薪酬体系是内部公平导向」。它把你推到一个必须证明「外面真的要你」的位置，而这件事一旦要证明，你就输了。

**作辅由头的正确用法**：放在最后一段，一句话，不展开。
> 「另外补充一个信息：同类岗位在市场上的区间大致在 X 到 Y，供您参考。」

说完就停，不等回应，不追问。

## 二、禁用由头清单（见到即改写）

| 禁用由头 | 为什么不能用 | 改写成 |
|---|---|---|
| 司龄年限（我干了八年） | 年限是「过去」，公司为「未来」付钱。这句话在 HR 耳里等于「没有增量」 | 职责累积的时间证据：「八年间职责从 A 扩到 A+B+C，最近一次扩项在 X 月」 |
| 生活成本（房贷、养家、物价涨） | 你的支出结构不是公司的定价依据。说了会让对方把话题转到「公司也有困难」 | 岗位价值：「这个岗位现在承担的价值，与我的薪酬位置不匹配」 |
| 同事对比（XX 比我高） | 涉及他人薪资，触碰保密红线，且把个人诉求变成内部矛盾 | 序列定位：「我想确认我的岗位在序列里的定位是否还准确」 |
| 离职倾向（不给就走） | 一次性消耗掉所有信任，且大概率被「那你走吧」反制 | 坦诚沟通：「我在这里有长期打算，所以想把薪酬的事谈清楚」 |
| 我很辛苦（加班、累） | 辛苦是过程，公司买的是结果。且暗示效率问题 | 产出：「用更少的人力覆盖了更多的事」 |
| 公司赚钱了 | 公司赚钱和给谁分钱是两件事，直接挂钩会被「你不在分配序列」挡回 | 排序：「如果今年有增量预算，倾斜顺序按什么排」 |
| 我需要被公平对待 | 「公平」是无法验收的诉求，对方无法回应 | 具体缺口：「我现在的绝对值在带宽的哪个位置」 |

## 三、无数字降级法（原提示词缺的那一环）

用户拿不出 ROI、成本节省这类硬数字时，**不要标 `[待补充]` 了事**。改成能被第三方核实的定性表述。

### 三句式结构

```
动作（你做了什么） + 对象（对谁/对什么） + 可核实结果（变成什么样）
```

### 改写对照表

| 用户原话 | 降级表述 | 为什么成立 |
|---|---|---|
| 带新人 | 承担 2 名新人 onboarding 与带教，独立上手周期从 3 个月压到 6 周 | 有对象、有前后对比，可向新人核实 |
| 事情变多 | 从只管投放，扩到投放 + 私域 + 复购，团队未增编 | 有边界变化，「未增编」是关键 |
| 救了个项目 | 接手延期的 A 项目，在预算内交付并完成客户续约 | 有具体项目、有结果 |
| 我什么都干 | 同时覆盖 A、B、C 三条线，其中 B 线原属另一岗位职责 | 用「原属另一岗位」证明超出 JD |
| 客户很喜欢我 | A 客户续约两次，续约时指定我继续对接 | 「指定我」是可核实的事实 |
| 我把流程理顺了 | 把 A 流程从 5 步压到 3 步，跨部门返工次数从每月 X 次降到 Y 次 | 有前后数字，哪怕是小数字 |
| 我帮了别的组 | 支持 B 组完成 C 项目交付，占我约 20% 工时 | 有比例，有对象 |

### 判据（一句话）

**这句话能不能被第三方核实？**
- 能核实 → 合法，不需要数字，不需要标 `[待补充]`
- 不能核实 → 说明还没想清，继续问，或者承认这次没料

### 一条都翻译不出来怎么办

直说：

> 「按你现在给的信息，这次申请缺一个能被审批逻辑接住的支点。硬写会得到一封听起来很努力、但对方无法回应的邮件，反而消耗一次机会。建议先用一个季度做出一件可核实的事——最好带一个前后对比的数字，下一个窗口我们再谈。」

这是负责，不是推诿。**让用户在一个不成立的时机去谈，才是真的害他。**

## 四、由头与涨幅的匹配表

| 主由头 | 涨幅经验区间 | 说明 |
|---|---|---|
| 职级带宽内校准 | 8%—20% | 低于中位时可达 20%+，属一次性校准，之后回归常规 |
| 职责扩展 / 岗位重估 | 10%—25% | 按职责增量占原岗位的比重折算 |
| 增量贡献 | 10%—25% | 按锚 B 折算，封顶不超过增量分享的合理比例 |
| 关键人才保留 | 15%—30% | 可结合结构收益，不必死磕底薪 |
| 窗口内优先级 | 5%—10% | 普调基础上加 2—5 个点 |
| 市场对标单独主谈 | 不建议 | 若坚持，按 8%—12% 保守给，并预告被挡回概率高 |

以上为经验区间，**不是承诺，也不是市场行情**。实际以公司带宽、预算与授权为准。所有数字必须由用户的实际薪资与脚本计算得出，不得直接引用本表作为报价。

**匹配检查**：若用户要的涨幅超出对应由头的上限，两条路——换更强的由头，或者把超出部分转到结构收益。不要用弱由头硬撑高涨幅，那是最容易被一句话击穿的组合。
