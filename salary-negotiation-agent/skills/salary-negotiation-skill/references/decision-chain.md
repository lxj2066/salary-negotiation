# 决策链与时机：谁在批、什么时候提

同样一封邮件，发给对的人、在对的时点，结果可能完全不同。原提示词问了「谁能批」却没用上答案，这份文件补的就是这一段。

---

## 一、决策链地图：四个角色

加薪审批不是一个人说了算，是一条链。四个角色，作用完全不同：

| 角色 | 通常是谁 | 他决定什么 | 你该怎么对待 |
|---|---|---|---|
| **提报人** | 直属领导 | 这件事**进不进流程** | 最重要的人。他的意愿决定你有没有机会 |
| **审核人** | HR / HRBP / 薪酬岗 | 这件事**按哪个由头受理** | 决定你的理由能不能套进制度 |
| **签字人** | 部门负责人 / 薪酬委员会 | 这件事**批多少** | 决定最终数字 |
| **否决点** | 财务（总量）、法务（合规）、更高层（排序） | 这件事**能不能被推翻** | 通常见不到，但要知道存在 |

### 一条关键判断

**绕过直属领导直接找上级，成功率远低于让直属领导成为你的提报人。**

原因不是「越级不礼貌」这种职场礼仪，而是机制：上级要批一件事，第一句话一定是「你领导怎么看」。如果答案是「他没提」，这件事就变成了「一个员工越过他的领导来找我」——这不是加薪问题，是管理问题，而管理问题的处理方式通常是压下去。

### 直属领导的授权边界

常见分级授权（区间来自公开薪酬管理实践，**以公司实际授权表为准**）：

| 层级 | 常规调薪权 |
|---|---|
| 直属主管 | 5%—8% |
| 部门负责人 | 8%—15% |
| HR / 薪酬委员会 | 15% 以上或跨带宽 |

这条信息的用法不是「那我直接找 HR」，而是：**当你要的涨幅超过直属领导的权限时，主动帮他把材料做足。** 他要往上走流程，材料越完整，他越愿意提。

具体动作：把你的由头、数据、市场区间整理成一页，发给他。**让他可以直接转发给上级。** 这是最有效的「借力」，因为你替他把最麻烦的部分做了。

### 谁最容易卡你

按经验，卡点出现的位置有规律：

| 卡点 | 常见理由 | 破法 |
|---|---|---|
| 直属领导不愿提 | 怕开了口子、怕自己被质疑管理能力、怕批不下来没面子 | 给「不会让他为难」的方案：涨幅控制在授权内，或先谈结构收益 |
| HR 口径不认 | 你的由头套不进制度 | 换由头（见 `references/cause-library.md`），让理由能被制度接住 |
| 签字人压总量 | 预算不够 | 争排序不争总量，或转结构收益 |
| 财务卡总量 | 人工成本超预算 | 这时任何个人努力都无效，只能等窗口 |

**最后一行很重要**：如果卡点是财务的总量控制，说明这不是你能谈的层面。此时继续推进只会消耗关系，正确动作是确认下一个窗口，然后停手。

## 二、企业类型适配

### 民企 / 成长型

| 维度 | 特征 |
|---|---|
| 决策链 | 短。老板或业务负责人一句话就能定 |
| 由头偏好 | 增量贡献、未来价值。对「你还能带来什么」最敏感 |
| 语气 | 可以直接。绕弯子反而显得不自信 |
| 关键动作 | 找**真正能拍板的人**，不是找流程上该找的人 |
| 常见挡回 | 「公司现在没钱」「再做出点成绩」 |

**策略**：把谈话重心放在「我接下来能带来什么」，而不是「我过去做了什么」。民企为未来付钱，为过去付钱的是大公司。

### 外企 / 成熟体系

| 维度 | 特征 |
|---|---|
| 决策链 | 长。有明确授权表与评审会 |
| 由头偏好 | 带宽分位、内部公平、市场对标。对「你值多少」有一套客观标准 |
| 语气 | 专业、克制。情绪化表达会直接减分 |
| 关键动作 | 材料要能套进制度。HR 是真正的守门人，不是障碍 |
| 常见挡回 | 「你的位置在带宽中段」「要走年度评审」 |

**策略**：不要试图用「我很重要」打动对方，要用「我的位置偏离了带宽标准」推动对方。**外企的破局点是校准，不是感动。**

### 国企 / 体系内

| 维度 | 特征 |
|---|---|
| 决策链 | 长且有隐性规则。工资总额管控是硬约束 |
| 由头偏好 | 岗位价值重估、绩效分配、专项奖励 |
| 语气 | 稳重。不突出个人，突出「岗位与贡献」 |
| 关键动作 | 走序列，不走个人申请 |
| 常见挡回 | 「总额就这么多」「要走职代会/评审」 |

**路径优先级（重要，原提示词缺这一条）**：

```
职级序列晋升  >  专项奖励 / 一次性激励  >  岗位津贴  >  底薪调整
```

**为什么职级晋升排第一**：职级晋升会**同步拉动所有挂钩项**——岗位津贴、公积金基数、年终系数、甚至通讯补贴标准。一次动作，多处生效。而底薪调整只动一个数，且受总额管控最严。

**所以体系内的正确问法不是「能不能给我涨薪」，是「我这个岗位对应哪个职级，晋升条件是什么」。**

### 不确定企业类型时

按**流程严格型**处理：
1. 先问决策链（谁能批、要不要往上走）
2. 再问窗口（什么时候调薪、有没有固定评审）
3. 语气走专业路线，由头落在「岗位定位」而非「个人贡献」

不确定时保守处理，比猜错方向安全。

## 三、时机信号（原提示词缺的部分）

时机是加薪里权重极高但最容易被忽略的变量。**同一个申请，早两周和晚两周，结果可能完全不同。**

### 正面信号（出现两个以上就可以提）

| 信号 | 为什么是好时机 |
|---|---|
| 刚交付里程碑 | 成果最新鲜，记忆成本最低 |
| 公司刚融资 / 财报超预期 | 有钱，且需要稳定团队 |
| 直属领导刚升职 | 他有新预算和新话语权，需要立信 |
| 年度预算编制前 1—2 个月 | 你的诉求能进预算，而不是从既有预算里挤 |
| 团队缺人且招聘冻结 | 你的替换成本被动上升，这是最硬的筹码 |
| 组织调整后职责重划 | 职责变化是天然的由头，不用自己论证 |
| 刚接手了超出原岗位的事 | 同上，且时效性强 |

**最值得记的一条**：**预算编制前 1—2 个月。** 这是唯一一个「你的诉求不占用别人预算」的窗口——钱还没分完，你是在参与分配，不是在抢别人的份额。错过这个窗口，后面所有努力都是在既有盘子里挤。

### 负面信号（出现一个就等）

| 信号 | 为什么该等 |
|---|---|
| 公司刚裁员 / 宣布冻结 | 此时提加薪，等于在火场里问能不能加薪 |
| 直属领导自己正在被考核 | 他没有余力也没有意愿替你争取 |
| 刚被拒不足 3 个月 | 复提会被视为纠缠，且会强化「这个人只关心钱」的印象 |
| 刚出过事故 / 绩效评级偏低 | 你的谈判位置是负的，任何诉求都会被反弹 |
| 跨年预算已锁 | 流程上就不可能，除非特批 |
| 公司正在被并购 / 重大重组 | 所有人事决策都会冻结 |

### 时机判断的输出格式

不要只说「现在时机合适/不合适」，要说清三件事：

```
当前时机：{合适 / 需等待 / 不成立}
依据：{命中了哪几个信号}
建议动作：{现在提 / 等到 X 时点 / 先做 Y 再提}
```

## 四、决策链与时机怎么合起来用

两个变量交叉，得到四种打法：

| | 时机好 | 时机差 |
|---|---|---|
| **决策链清晰** | **直接打**：备好材料，约谈，走流程 | **预约打**：现在锁定窗口日期，材料先备好 |
| **决策链模糊** | **先探后打**：先用一次非正式沟通摸清谁能批、预算在哪 | **只做准备**：摸清决策链 + 攒一件可核实的事，等窗口 |

**最忌讳的组合**：决策链模糊 + 时机差，却硬要发正式邮件。这是消耗机会最快的方式——正式流程走过一次被拒，同一个由头在半年内基本不能再用。

---

## 五、一句话记住这份文件

**加薪是流程问题，不是说服问题。** 找对人、在对的窗口、用制度认的由头、报有依据的数——四件事做成，说服的部分其实很短。
