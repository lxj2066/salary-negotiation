# 加薪谈判顾问 · salary-negotiation-agent

版本 1.1.0

一个坐在**员工这一侧**的加薪谈判专家。不是帮你把邮件写漂亮，是帮你把这件事谈成。

内嵌技能：`skills/salary-negotiation-skill`（v1.1.0）

---

## 它解决什么

加薪谈不成，通常不是话术不好，是三件事没想清楚：

| 卡点 | 常见做法 | 这个专家怎么做 |
|---|---|---|
| **要多少** | 凭感觉报一个数，被压就退 | 三锚定价（带宽分位 / 可持续增量 / 市场价推出的替换成本），给开口锚、目标锚、底线锚三个数，脚本算，不口算 |
| **凭什么** | 「我很努力」「我干了很多」 | 无数字降级法：动作 + 对象 + 可核实结果。翻不出来就直说这次时机不成立 |
| **不批怎么办** | 「那我再等等」 | 30/60/90 复谈日历 + 结构收益按兑现确定性排序 + BATNA 自评 |
| **人怎么受得了** | 没人管 | 谈前一句、被拒当场一句、被拒当晚怎么做、谈崩后怎么上班 |

最后一条不是附加项。加薪既是流程，也是关系行为——谈完还要一起开会。

---

## 怎么用

三个入口，对应三种最常卡住的时刻：

1. **不知道怎么开口**：「我想跟公司谈涨薪，但不知道从哪开口，帮我把方案和话术准备出来。」
2. **被拒过，想再谈一次**：「我上次提加薪被拒了，现在想找机会再谈一次，该怎么开这个口？」
3. **不知道该要多少**：「我想知道自己该要多少，帮我按带宽和职责变化算一个涨幅区间。」

它会先问 2—4 个关键问题（最能说明你值更多的一件事、岗位序列、带宽位置），拿到回答后输出七件套：

1. 场景与由头判断
2. **谈前一句**（≤30 字，带进会议室）
3. 预沟通脚本
4. 正式邮件（250 字内）
5. 面谈话术（六节点 + 七类挡回）
6. 结构收益备选
7. 时机与复谈日历（含**被拒后第一句**）

---

## 它会劝你别谈

这是它最有价值的部分，也是最容易被误解的部分。

当弹药为零（既无增量也无职责变化）、或负面信号命中两个以上（刚裁员、领导正被考核、刚被拒不足三个月），它会直说这次时机不成立，并告诉你下一步该做什么——而不是硬写一封听起来很努力、对方却无法回应的邮件。

一次正式申请被拒，同一个由头半年内基本不能再用。**拦下这一次，比交付一封邮件更负责。**

---

## 三条边界

1. **不承诺结果**。不保证能谈成。保证的是：你报的数有依据，对方压价时必须给理由。
2. **不做法律判断**。欠薪、违法调岗、变相降薪超出范围，建议咨询劳动法律师。
3. **数字都是你的**。脚本里的经验区间是行业经验值，不是市场行情，也不是承诺。
