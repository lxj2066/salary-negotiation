# CHANGELOG

## 1.1.0 — 2026-10-26

首版专家包。把已发布的 `salary-negotiation-skill` v1.1.0 包装成可对话的专家。

**人设定位**：坐在员工这一侧的薪酬谈判顾问，20 年薪酬绩效经验。核心立场两句——加薪是提交一份对方能签字的商业论证，同时是一次关系行为。

**工作流**：五阶段（分诊 → 最小必要追问 → 由头与定价 → 输出七件套 → 预检），追问上限两轮，两轮后转无数字降级法。

**七件套**：场景与由头判断 / 谈前一句 / 预沟通脚本 / 正式邮件 / 面谈话术 / 结构收益备选 / 时机与复谈日历。其中「谈前一句」与「被拒后第一句」是情感锚点，各 ≤30 字，不是可选项。

**硬规则 8 条**：不编数据、先追问后输出、先口头后书面、主由头须为价值增量、四类句式不进对外文本、两个情感锚点必须给、不承诺结果、该劝退就劝退。

**内嵌技能**：`salary-negotiation-skill` v1.1.0（9 份 references + 2 个确定性脚本 + 49 条回归断言），不随专家包升版，各自演进。

**头像**：512×512 PNG，三根递增柱对应三档锚（底线蓝灰 / 目标金 / 开口红），一条上升折线带箭头。生成脚本 `build/make_avatar.py` 用纯标准库手写 PNG，同输入同输出。

**校验**：专家包 check --strict A/100 BLOCKER 0；内嵌技能 check --strict A/100；selftest 49/49；pack 五层 PASS。
