# 加薪谈判作战包 · salary-negotiation-skill

把「我想涨薪」变成「这件事按公司逻辑应该批，批多少、凭什么、退到哪」。

一套给**雇员本人**用的加薪谈判工具：先判断场景与由头，再算涨幅三档锚，然后给预沟通脚本、邮件正文、面谈话术、结构收益备选和拒绝后复谈日历。

---

## 它解决什么

市面上大多数「加薪助手」提示词做的是「怎么说得体」。得体只是及格线。真正决定成败的是三件事，这套包补的就是这三件：

| 缺口 | 原提示词的样子 | 本包的做法 |
|---|---|---|
| **要多少** | 反复要求「给区间」，但从没说区间怎么算 | 三锚定价（带宽分位 / 增量折算 / 替换成本）+ `salary_calc.py` 脚本，模型不口算 |
| **凭什么** | 硬规则禁编数据，但用户就是没有数字，只能标 `[待补充]` | 无数字降级法：动作 + 对象 + 可核实结果，翻译不出就直说时机不成立 |
| **不批怎么办** | 只有「约定再谈」，没有节点 | 30/60/90 复谈日历 + 结构收益按兑现确定性分级 + BATNA 自评 |

另外补了原版没有的：七类高频挡回的应答、口头当场被否的三步、决策链影响力地图、时机正负信号、邮件主题行策略、见领导前 5 分钟速览卡。

完整审计见 `references/audit-report.md`（14 项，按 P0/P1/P2 分级）。

## 怎么用

### 直接对话

```
我要跟公司谈涨薪，现在月薪 20000，带宽大概是 15000/22000/28000，帮我准备一套方案
```

技能会先问 2—4 个关键问题（过去一年最能说明你值更多的一件事、岗位序列、带宽位置），拿到回答后输出六件套。

### 单独跑定价

```bash
python scripts/salary_calc.py --current 20000 --scene role --firm private \
  --band-min 15000 --band-mid 22000 --band-max 28000 --increment 600000
```

输出：

```
开口锚 Ask    30,100 元   ← 第一次报这个数
目标锚 Target 25,500 元   ← 心里真实目标，不主动说
底线锚 Walk   22,000 元   ← 低于此值改谈结构收益

目标涨幅      27.5%   该由头经验区间 10%—25%
结构收益缺口  3,500 元/月（42,000 元/年）
```

参数：

| 参数 | 说明 |
|---|---|
| `--current` | 当前月薪，必填 |
| `--scene` | 主由头：`band` 带宽校准 / `role` 职责扩展 / `contribution` 增量贡献 / `retention` 关键人才 / `window` 窗口优先 / `market` 市场对标 |
| `--firm` | 企业类型：`private` 民企 / `mnc` 外企 / `soe` 国企 / `unknown` |
| `--band-min/mid/max` | 职级带宽，三项一起给才启用锚 A |
| `--increment` | 你带来的年化增量收益（元） |
| `--target-pct` | 你自己的期望涨幅，给了就覆盖加权值 |
| `--json` | 输出 JSON，便于二次处理 |

### 交付前自检

```bash
python scripts/preflight.py --file 你的输出.md --facts 20000,25000
```

拦五类：禁用句式（卖惨 / 比较 / 威胁 / 年限）、未填占位符、无出处数字、邮件超 250 字、六件套缺件。有 FAIL 退出码 1。

## 三条边界（重要）

1. **不承诺结果**。这套包不保证能谈成。它保证的是：你报的数有依据，对方压价时必须给理由。
2. **不做法律判断**。涉及欠薪、违法调岗、变相降薪，超出本包范围，请咨询劳动法律师。
3. **数字都是你的**。脚本里的经验区间（分享比例、开口倍数、涨幅区间）是行业经验值，不是市场行情，也不是承诺。所有具体数字必须来自你提供的输入。
