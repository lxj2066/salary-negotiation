# 加薪谈判作战包 · salary-negotiation-skill

把「我想涨薪」变成「这件事按公司逻辑应该批，批多少、凭什么、退到哪」。

一套给**雇员本人**用的加薪谈判工具：先判断场景与由头，再算涨幅三档锚，然后给谈前一句、预沟通脚本、邮件正文、面谈话术、结构收益备选、拒绝后第一句与复谈日历。

版本 1.1.0。

---

## 它解决什么

市面上大多数「加薪助手」提示词做的是「怎么说得体」。得体只是及格线。真正决定成败的是四件事，这套包补的就是这四件：

| 缺口 | 原提示词的样子 | 本包的做法 |
|---|---|---|
| **要多少** | 反复要求「给区间」，但从没说区间怎么算 | 三锚定价（带宽分位 / 可持续增量 / 市场价推出的替换成本）+ `salary_calc.py`，模型不口算 |
| **凭什么** | 硬规则禁编数据，但用户就是没有数字，只能标 `[待补充]` | 无数字降级法：动作 + 对象 + 可核实结果，翻译不出就直说时机不成立 |
| **不批怎么办** | 只有「约定再谈」，没有节点 | 30/60/90 复谈日历 + 结构收益按兑现确定性分级 + BATNA 自评 |
| **人怎么受得了** | 全篇是机制与判据，没有一个字讲情绪 | 情感线：谈前一句、被拒当场一句、被拒当晚怎么做、谈崩后怎么收场 |

最后一条不是附加项。**加薪既是流程，也是关系行为**——谈完还要一起开会，被拒那晚还要睡觉。只做前三条，这套东西在最需要被打开的那个晚上不会被打开。

完整审计见 `references/audit-report.md`：初版 14 项 + 二轮复审 6 项，按 P0/P1/P2 分级。

## 怎么用

### 直接对话

```
我要跟公司谈涨薪，现在月薪 20000，带宽大概是 15000/22000/28000，帮我准备一套方案
```

技能会先问 2—4 个关键问题（过去一年最能说明你值更多的一件事、岗位序列、带宽位置），拿到回答后输出七件套。

### 单独跑定价

```bash
python scripts/salary_calc.py --current 20000 --scene role --firm private \
  --band-min 15000 --band-mid 22000 --band-max 28000 \
  --increment 600000 --market 24000
```

输出：

```
开口锚 Ask    28,000 元   ← 第一次报这个数（已压回带宽上限）
目标锚 Target 25,000 元   ← 心里真实目标，不主动说
底线锚 Walk   21,200 元   ← 低于此值改谈结构收益

目标涨幅      25.0%   该由头经验区间 10%—25%
结构收益缺口  3,800 元/月（45,600 元/年）
流程提示      超出直属主管授权，需往上走；材料备成一页可转发版
```

参数：

| 参数 | 说明 |
|---|---|
| `--current` | 当前月薪，必填 |
| `--scene` | 主由头：`band` 带宽校准 / `role` 职责扩展 / `contribution` 增量贡献 / `retention` 关键人才 / `window` 窗口优先 / `market` 市场对标 |
| `--firm` | 企业类型：`private` 民企 / `mnc` 外企 / `soe` 国企 / `unknown` |
| `--band-min/mid/max` | 职级带宽，三项一起给才启用锚 A |
| `--increment` | 年化**可持续**增量收益（元） |
| `--increment-type` | `recurring`（默认，进底薪）/ `oneoff`（一次性，走奖金，锚 B 跳过） |
| `--market` | 外部同岗市场月薪（元）。**锚 C 必需**，缺则锚 C 不参与 |
| `--target-pct` | 你自己的期望涨幅，给了就覆盖加权值 |
| `--json` | 输出 JSON，便于二次处理 |

**三锚各有前提，缺了就不参与，不硬凑：**

| 锚 | 前提 | 缺了怎么办 |
|---|---|---|
| A 带宽分位 | 带宽三项 | 跳过 |
| B 增量折算 | 可持续增量 | 跳过；一次性的走奖金 |
| C 替换成本 | 外部市场价 | 跳过，并说明「没有市场价算不出替换成本」 |

### 交付前自检

```bash
python scripts/preflight.py --file 你的输出.md --facts 20000,25000,24000
```

拦六类：禁用句式（卖惨 / 比较 / 威胁 / 年限）、未填占位符、无出处数字、邮件超 250 字、七件套缺件、**情感锚点缺失 + 空话**。有 FAIL 退出码 1。

## 两个情感锚点

七件套里有两项不是流程，是给人用的：

| 锚点 | 位置 | 例子 |
|---|---|---|
| **谈前一句** | 预沟通脚本之前 | 「我不是来要钱，是来核对职责和报酬还配不配。」 |
| **被拒后第一句** | 复谈日历之前 | 「我需要想一下，能不能明天再跟您聊十分钟？」 |

要求：≤30 字、能背下来、不用感叹号。被拒那句必须是**请求**（要时间、要信息），不是表态。

「相信自己」「加油」「会好的」被写进预检的禁用清单——它们不是话，是噪音，被拒当场说不出口。

## 三条边界（重要）

1. **不承诺结果**。这套包不保证能谈成。它保证的是：你报的数有依据，对方压价时必须给理由。
2. **不做法律判断**。涉及欠薪、违法调岗、变相降薪，超出本包范围，请咨询劳动法律师。
3. **数字都是你的**。脚本里的经验区间（分享比例、开口倍数、涨幅区间）是行业经验值，不是市场行情，也不是承诺。所有具体数字必须来自你提供的输入。
