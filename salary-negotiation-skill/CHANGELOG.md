# CHANGELOG

## 1.1.0 — 2026-10-26

二轮复审。查「逻辑是否自洽」与「情感是否被照顾到」，查出 6 项，其中 3 项是 1.0.0 自己引入的错误。

### 逻辑修正（P0，3 项，全部是 1.0.0 的错误）

- **锚 C 从伪锚改成真锚**。1.0.0 的 `Target(C) = 现有 × 1.3125` 不含任何个体信息，是给薪资乘常数。改为由**外部市场价**推出替换成本：`替换年成本 = 市场月薪 × 12 × 1.2 + 市场月薪 × 上手折损`。没有市场价则锚 C 不参与，并说明原因。
- **开口锚加带宽上限约束**。1.0.0 允许 Ask 超出岗位上限（实测 30100 vs 上限 28000），在体系内会被判定「不懂定价」。改为 `Ask = min(Target × mult, 带宽上限)`，超出部分转结构收益。
- **底线锚改三条约束**。1.0.0 的「不低于带宽中位」在当前薪资低于中位时，会把底线抬成第二目标（实测现有 20000、底线 22000）。改为 `≥ 现有×1.03 且 ≤ 目标×0.85`，中位降为参考落点。

### 逻辑补强（P1，2 项）

- 增量区分 `recurring` / `oneoff`。一次性收益不折算底薪，改为提示走项目奖金。
- 授权联动：涨幅 > 8% 时输出 `needs_escalation`，提示材料要备成可转发给上级的版本。`scene=market` 增加降档警告。

### 情感补强（P0，1 项含 5 个子项）

- 新增 `references/emotional-line.md`：谈前羞耻感处理、开口三版、被拒当场三秒、被拒当晚三不做三要做、谈崩后的关系保全、劝退三段式。
- 六件套 → **七件套**，新增第 2 项「谈前一句」；第 7 项内含「被拒后第一句」。两句均为 ≤30 字、可背诵的情感锚点。
- `SKILL.md` 主张改为两句：既是商业论证，也是关系行为。
- 红线加 8、9 两条：不安慰化不空话化；不把自我价值绑在结果上。
- 降级表加「用户刚被拒、情绪重」先处理当晚再谈日历。

### 工程

- `preflight.py` 五类 → 六类：新增情感锚点缺失检查与空话检测（相信自己 / 加油 / 会好的 / 机会还有很多）。
- `tests/selftest.py` 28 → 49 条断言。
- **断言口径修正说明**：原「开口锚 = 目标×1.18」「底线锚 = 带宽中位」两条断言是按错误算法写的。算法修正后，断言改为直接检验约束（不超上限、不低于现有×1.03、不高于目标×0.85），而不是检验具体数值。这不是放宽断言，是换更硬的判据。
