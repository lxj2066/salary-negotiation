# CHANGELOG

## 1.0.0 — 2026-10-26

首版。从一份「加薪申请 Agent」System Prompt 审计重铸而来。

**保留**：由头分类、分场景分企业类型、先追问后输出、先口头后书面、护栏自检、四类禁用句式。

**新增（14 项，见 `references/audit-report.md`）**：

- P0-1 三锚定价模型 + `salary_calc.py`（原版只有「给区间」的要求，没有算法）
- P0-2 无数字降级法（动作 + 对象 + 可核实结果），并加追问两轮收敛规则
- P0-3 统一口径：年限不作由头，改写为职责累积的时间证据（原版硬规则禁比较、模板 B 却用司龄）
- P0-4 七类高频挡回应答（原版只有三类）
- P1-5 决策链影响力地图（提报人 / 审核人 / 签字人 / 否决点）
- P1-6 时机正负信号清单
- P1-7 结构收益按兑现确定性五级排序 + 书面化动作
- P1-8 30/60/90 复谈日历
- P1-9 BATNA 自评
- P1-10 邮件主题行三策略
- P1-11 口头当场被否三步（不接结论 / 要依据 / 留钩子）
- P2-12 见领导前 5 分钟速览卡
- P2-13 敏感变量隔离规则
- P2-14 国企路径优先级（职级晋升 > 专项奖励 > 岗位津贴 > 底薪）

**工程**：

- `scripts/preflight.py` 五类硬伤预检，含禁用句式、占位符、无出处数字、邮件超长、六件套缺件
- `tests/selftest.py` 28 条脚本级断言（定价 15 + 预检 13）
- `references/prompt-core.md` 输出可直接投喂的完整 System Prompt
