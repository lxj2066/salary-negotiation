# 话术库：六个节点 + 七类挡回 + 当场被否 + 复谈日历

原提示词给了六个节点，这次补了三块：**七类高频挡回**、**口头当场被否的三步**、**30/60/90 复谈日历**。

统一格式：**错误版 / 正确版 / 为什么**。错误版不是编出来凑数的，都是真实谈判里高频出现的失手。

---

## 一、六个基础节点

### 节点 1 · 开场

| | |
|---|---|
| 错误版 | 「领导，我最近压力挺大的，房贷涨了，孩子也要上学……」 |
| 正确版 | 「想占用您 20 分钟，聊一下我的职责和薪酬安排。我先说结论，再说依据，您看行吗？」 |
| 为什么 | 开场 30 秒定框架。用「压力」开场，这 20 分钟就变成情绪沟通；用「职责和薪酬」开场，它才是议题沟通。最后那句「我先说结论再说依据」，是替对方节省注意力，也是在争取陈述权 |

### 节点 2 · 摆成绩

| | |
|---|---|
| 错误版 | 「我这一年特别努力，经常加班到十点。」 |
| 正确版 | 「去年我负责 A 线，带来 X 万增量，这块不在我原本的目标里。另外从 Q3 起我接了 B 线，团队没加人。」 |
| 为什么 | 努力是过程，公司买结果。无数字时用降级法：「带新人 → 承担 2 名新人带教，上手周期从 3 个月压到 6 周」。**关键是「不在原本目标里」这句**——它把「完成本职」和「超额贡献」区分开，这是全段最值钱的七个字 |

### 节点 3 · 谈预期

| | |
|---|---|
| 错误版 | 「您看能给我涨多少？」 |
| 正确版 | 「我算了一下，结合职责范围和市场区间，我期望的区间是 X 到 Y。您看这个区间在公司这边现实吗？」 |
| 为什么 | 问「能涨多少」等于把定价权完全交出去，对方说一个数，你只能接受或翻脸。给区间 + 请对方反馈，保留了定价参与权。**区间下限是你的可接受值，上限是有依据的高点**，不要给一个自己都不信的虚高数 |

### 节点 4 · 遇预算紧张

| | |
|---|---|
| 错误版 | 「那……那就算了，我理解。」 |
| 正确版 | 「理解预算有约束。如果底薪这块暂时动不了，能不能在奖金系数、项目分配或带教津贴上做结构性安排？这样对公司成本压力小一些，对我也有实际激励。」 |
| 为什么 | 「那就算了」是自我关闭。换科目不是退让，是**把单选题改成多选题**——底薪是硬成本，奖金系数是浮动的，对公司来说后者的当期压力确实更小。这不是话术，是真的对双方都更优 |

### 节点 5 · 遇画饼

| | |
|---|---|
| 错误版 | 「好的，我等公司发展好了再说。」 |
| 正确版 | 「明白。那我想确认一下：达到什么目标、大概什么时间点、由谁来确认，可以重新评估这件事？」 |
| 为什么 | 「等公司发展好」是一张没有兑付条件的支票。三件套（标准 / 时间 / 确认人）缺任何一个，这个承诺就等于零。**问的时候语气要平，不要像在质疑**——你的目的是拿到可执行的东西，不是让对方难堪 |

### 节点 6 · 被拒后

| | |
|---|---|
| 错误版 | 「行吧。」（然后开始投简历，或者在群里抱怨） |
| 正确版 | 「我接受这个结果。想请教一下，从我现在的状态到能批的程度，中间的差距主要在哪？我按这个方向做，三个月后能不能再来跟您对一次？」 |
| 为什么 | 被拒不是结束，是**拿到了一份诊断报告**。请教差距（而不是争辩）能让对方说出真实原因，而真实原因往往和第一次给的理由不同。最后那句「三个月后再来」，是当场锁定下一次入场券 |

## 二、七类高频挡回（原提示词缺的部分）

挡回不可怕，接不住才可怕。每一条都拆成三层：**对方说的 → 他真正在说什么 → 你怎么接**。

### 1.「今年普调已经含了你的」

- **真实含义**：把你归入常规池，不打算单独立项。这是最省事的挡回，因为它听起来像已经给了你什么
- **应答**：「普调我收到了，这块我理解是覆盖整体调整的。我想谈的是另一件事——我这个岗位在序列里的定位是否还准确，因为我实际做的事已经超出最初的岗位描述。」
- **要点**：不要否定普调（那会显得不知足），要**把话题从「涨幅」移到「序列定位」**。序列定位一旦松动，钱是自动跟上的

### 2.「你的涨幅已经高于平均了」

- **真实含义**：用横向比较封顶。平均涨幅是个统计结果，跟你的价值无关
- **应答**：「平均我信。不过我更关心绝对值——我现在的绝对值在带宽里大概是什么位置？如果位置偏低，那高于平均可能只是补历史差额。」
- **要点**：不接平均值，接绝对值。平均值是相对数，可以被任何人解释；带宽位置是绝对数，公司内部有客观标准

### 3.「公司今年效益不好」

- **真实含义**：预算收紧，但通常不是零。效益不好时公司照样会批一部分人，只是池子小了
- **应答**：「理解。那我想了解一下，如果总量确实有限，这个池子的倾斜顺序是按什么排的——绩效等级、业务线优先级、还是岗位稀缺度？我想知道自己排在哪一档。」
- **要点**：**不争总量，争排序**。总量你争不动，排序规则一旦说出口，就有了下一次的依据

### 4.「再等等，明年一定」

- **真实含义**：口头承诺，对对方零成本。这句话在 90% 的情况下会在明年变成「今年情况特殊」
- **应答**：「行，那我按这个方向准备。想跟您确认三个事：一是达到什么标准，二是什么时间点评估，三是由谁来确认。我好按这个来安排。」
- **要点**：三件套缺一即为无效承诺。如果对方三个都不肯给，说明这个承诺本身就是挡回，你要做的是记下来，不再指望它

### 5.「你先做出成绩再说」

- **真实含义**：门槛后移。这句最麻烦，因为「成绩」没有定义，你可以永远差一点
- **应答**：「可以。那我们把『成绩』定下来吧——如果我做到 A、B、C 这三件，是不是就可以重新评估？我想把标准说清楚，免得做完发现方向不对。」
- **要点**：**当场把「成绩」定义成可验收的三条**，并落书面（会后邮件确认）。没有定义的成绩要求，是无限期的拖延

### 6.「你的岗位就是这个价」

- **真实含义**：他在说岗位价值，不是个人价值。这句话其实是在承认「你的薪酬符合你的岗位」，那么破法就是证明「你的实际职责已超出这个岗位」
- **应答**：「岗位的定价我认同。问题是我现在做的事已经超出这个岗位的描述了——{具体举两件}。所以想确认的是，是我该按现在这个岗位继续做，还是这个岗位的定位该更新了？」
- **要点**：不要争「我值更多」（那是主观），要争「职责已超出 JD」（那是客观）。**给对方两个选项，两个都对你有利**：要么更新岗位（涨薪），要么减少职责（减负）

### 7.「涨薪要走年度窗口，现在不行」

- **真实含义**：流程约束，这一条可能是真的。大公司确实有固定窗口
- **应答**：「明白，那我按流程来。想确认两件事：窗口大概什么时候开，提报截止日是哪天？我提前把材料准备好。」
- **要点**：这是唯一一条**应该直接接受**的挡回，但要当场锁两个日期。**窗口类挡回的价值在于它给了你一个确定的准备期**，别浪费在争辩上

## 三、口头沟通当场被否：三步

真实高频场景：你刚开口，领导当场就说「现在不行」「这个我说了不算」「你先把 XX 做好」。

当场最忌两件事：**继续争辩**（把沟通变成对抗）、**立刻退让**（「好的我理解」等于自己把门关上）。

### 第一步 · 不接结论

> 「我理解。方便的话我想了解一下，主要是卡在预算，还是卡在岗位定位？」

作用：把「不行」这个整体结论，拆成可处理的具体原因。**只要对方开始解释原因，对话就没有结束。**

### 第二步 · 要依据

> 「如果是预算，今年倾斜的顺序大概是怎么排的？」
> 「如果是岗位定位，我这个岗位在序列里应该对应哪一级？」

作用：拿到排序信息或定位标准，就有了下一次的切入点。这一步的产出比「这次批不批」更值钱。

### 第三步 · 留钩子

> 「那我按您说的这个方向做，三个月后我再来跟您对一次，可以吗？」

作用：当场锁下一个时间点。**没有时间点的「以后再说」，等于没有下一次。** 对方点头之后，回去发一封确认邮件（见复谈日历 D+3）。

### 一条纪律

当场被否之后，**不要在同一个场合再提第二次**。第一次是沟通，第二次就是纠缠。把力气留到三个月后。

## 四、不用 offer 的等价表达（用户想用 offer 施压时给这条）

用户提「我拿到 offer 了，能不能拿去谈」，先明确说不建议（会一次性消耗信任，且大概率被「那你走吧」反制），然后给等价表达：

> 「我在这里有长期打算，所以想把薪酬的事一次谈清楚，而不是等到某天被动做决定。」

这句话传递的信息量和 offer 差不多（我有选择、我在认真评估），但**没有把关系推到对立面**，也没有给对方「你必须现在证明你值这个价」的压迫感。

**决定权交用户**：把两条路的后果说清，让用户选。不替他决定，但要说清代价。

## 五、复谈日历 30/60/90（原提示词缺的部分）

「下次再谈」在 90% 的情况下等于「永远不谈」——因为没有时间锚点，双方都不会主动重启。所以必须落日历。

### D+3 · 确认邮件（最重要的一封）

口头谈完三天内发，**不催结果，只留记录**：

```
主题：关于{日期}沟通的跟进 — {姓名}

{领导称呼}：

感谢今天的时间。把聊到的几点记录一下，如有理解偏差请指正：

1. 我需要在{方向}上做到{标准}；
2. 大概在{时间点}可以重新评估；
3. 届时由{确认人}确认。

我按这个安排推进，有进展随时同步。

{姓名}
```

**为什么 D+3 最重要**：口头共识会在两周内被双方重新解释，尤其是对自己有利的那部分。一封平实的确认邮件，把共识钉成文字，成本极低，作用极大。**而且它不催任何东西，所以不会引起反感。**

### D+30 · 进展沟通（15 分钟，不谈钱）

带一件新交付物，做一次短沟通。目的不是推进薪酬，是**保持话题活着**。

> 「按上次说的方向，我这边做完了 X，同步一下。另外想确认一下，这个方向是您期待的吗？」

**不谈钱**是纪律。第二次就谈钱，会显得你只关心钱；第二次只谈事，第三次谈钱才顺理成章。

### D+60 · 正式复评

标准已达成 → 正式提复评，带上 D+3 那封邮件作依据：

> 「上次约定的三条，A 和 B 已经完成，C 在推进中。想按当时的约定，把薪酬的事重新评估一次。」

标准未达成 → 不硬提，改确认差距：

> 「A 完成了，B 还差一块。我想确认一下差的部分是我理解偏了，还是标准需要调整。」

### D+90 · 窗口准备或重估 BATNA

- 有下一窗口 → 进入提报准备，材料复用模板 C
- 三次无实质进展 → 说明这家公司在这个岗位上给不了你要的东西，重估 BATNA（见 `references/guardrails.md`）

**D+90 的意义**：给这件事一个期限。没有期限的等待，会把一次谈判拖成一种状态。

## 六、话术使用的三条元纪律

1. **一次只推一件事**。同一场谈话里既谈钱又谈职级又谈带团队，对方只会记住最容易拒绝的那一件。
2. **每句话都要能接住对方的下一句**。写完一段话术，自己演一遍对方可能的三种回应，接不住的句子删掉。
3. **不背台词**。这些话术是结构，不是逐字稿。逐字背出来的话术，语气一定是假的，而语气比内容更容易被识破。
