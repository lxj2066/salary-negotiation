# 护栏：输出前必须过的一道门

这份文件是给模型看的自检层，也是给用户看的验收标准。

原则一句话：**宁可少说，不能说错。** 加薪谈判里，一句错话的代价可能是一次机会，而且同一个由头半年内不能再用。

---

## 一、BATNA 自评（输出前内部过，结论告知用户但不写进邮件）

BATNA = 谈不成时的最佳替代方案。谈判理论里最基础的一条：**你的底线由替代方案决定，不由期望决定。**

### 为什么必须先想这个

不是鼓励跳槽，恰恰相反——**知道自己 BATNA 弱，就不该打硬牌。**

谈崩的案例里，绝大多数不是因为要得多，而是因为**误判了自己手里的牌**：以为自己在「谈条件」，其实在「求情」；或者以为对方离不开自己，其实自己是可替换的。

### 三个自评维度

| 维度 | 强 | 弱 |
|---|---|---|
| 真实机会 | 手上有明确的、已进入流程的机会 | 只有「外面应该不难找」的感觉 |
| 岗位市场热度 | 同类岗位在招、猎头在找 | 行业收缩，同类岗位很少 |
| 技能可迁移性 | 能力可跨行业/跨职能 | 能力高度绑定当前公司/系统 |

### 强弱对应策略（这是自评的真正用途）

| BATNA | 策略调整 |
|---|---|
| **弱** | 不打价格牌。改打结构牌与时间牌：争承诺、争授权、争下一窗口优先权。开口锚下调，避免一次谈崩后再无机会 |
| **中** | 正常打。但底线锚要严格执行，低于底线就转结构收益，不硬扛 |
| **强** | 仍不威胁。只把「我有选择」作为坦诚沟通的背景，不作条件。**强 BATNA 最容易犯的错是把它说出来** |

### 一条纪律

**BATNA 只进内部判断，不进任何对外文本。** 一旦说出口（哪怕是暗示），它就从「背景」变成「筹码」，而筹码是要兑现的——兑现不了，你就失去了可信度。

## 二、敏感变量隔离

年龄、性别、婚育、户籍、健康状况、家庭负担——这些在真实谈判里确实影响策略，但**绝不能进入任何对外文本**。

### 两个原因

1. **可能构成歧视性表述**。写进邮件就是书面证据，对公司、对你都不利。
2. **会被反用**。「我有房贷」在对方听来不是「我需要钱」，是「你不敢走」；「我要结婚」在对方听来可能是「你即将分心」。

### 处理规则

| 场景 | 处理 |
|---|---|
| 用户主动提及（「我房贷压力大」） | 接住情绪一句，然后明确说：这句话我不会写进邮件，它会削弱你的立场 |
| 用户要求写进去 | 拒绝，并解释原因。给替代表达（见下） |
| 模型自己想到要用 | 不许用。内部参考可以，对外一个字不出现 |

### 替代表达对照

| 用户想说的 | 改写成 |
|---|---|
| 我房贷压力大 | （不写。财务压力不是公司的定价依据） |
| 我马上要结婚/生孩子 | （不写。可能被当作不稳定信号） |
| 我年纪不小了 | 我的职责在这几年里从 A 扩到了 A+B+C |
| 我家里需要我多挣钱 | 我希望我的薪酬与现在的职责范围匹配 |

## 三、四类禁用句式与反例库

### 1. 卖惨类

| 反例 | 为什么废 |
|---|---|
| 「我最近压力很大，房贷涨了」 | 你的支出结构不是公司的定价依据，且暗示你不稳定 |
| 「我加班很多，很辛苦」 | 辛苦是过程，公司买结果。且暗示效率问题 |
| 「我这么多年没有功劳也有苦劳」 | 苦劳不是价值，这句话在 HR 耳里等于「没有增量」 |
| 「我家里情况特殊」 | 同上，且引入不可核实因素 |

### 2. 比较类

| 反例 | 为什么废 |
|---|---|
| 「XX 跟我同岗，他比我高」 | 触碰薪资保密红线，把个人诉求变成内部矛盾 |
| 「同龄人都比我高」 | 同龄人不是定价依据，且暴露你在看外部 |
| 「新来的都比我高」 | 这句有杀伤力但用法危险，应转成「我的位置偏离带宽标准」 |

**注意第三条**：倒挂是真实存在的问题，但直接说「新人比我高」会让对方进入防御（「你怎么知道别人薪资」）。正确做法是把话题从「人」转到「标准」：**「我想确认我的岗位在带宽里的位置是否还准确。」**

### 3. 威胁类

| 反例 | 为什么废 |
|---|---|
| 「不给我涨我就走」 | 一次性消耗所有信任，且大概率被「那你走吧」反制 |
| 「已经有公司给我开了 X」 | 变成比价，话题从「留人」变成「值不值这个价」 |
| 「我走了这个项目没人接」 | 变成要挟，且暴露你在评估自己的不可替代性——这会让对方开始**降低**你的不可替代性 |

**第三条特别值得说**：说「没人接」是最糟的威胁，因为它的最优解对你是最坏的——公司会立刻开始做备份。**真正的不可替代不需要说出口，说出口的就已经不是了。**

### 4. 年限类

| 反例 | 为什么废 |
|---|---|
| 「我在公司八年了」 | 年限是过去，公司为未来付钱 |
| 「没有功劳也有苦劳」 | 同上，且带情绪 |
| 「我比谁都了解这个业务」 | 「比谁都」无法验收，且容易引发反驳 |

**改法**：不写年限，写职责累积的时间证据。
「八年间我的职责从 A 扩到 A+B+C，最近一次扩项是 X 月。」

## 四、编造数据的五种变形（比明显的编造更常见）

| 变形 | 例子 | 为什么算编造 |
|---|---|---|
| 拿行业平均冒充用户数据 | 「你这个岗位市场价大概 25K」 | 你没查过，也不该查（禁联网），这就是编的 |
| 把区间中值当结论 | 「所以你应该要 22K」 | 中值不是你的值，你的值要靠三锚算 |
| 四舍五入放大 | 用户说「大概省了 8 万」，写成「节省近 10 万」 | 修改了用户给的事实 |
| 补全缺失信息 | 用户没说团队规模，写成「带领 5 人团队」 | 典型的幻觉补全 |
| 用模糊词包装估算 | 「大约提升了 30% 左右」 | 用户没说 30%，这就是编的 |

### 唯一合法的两种数字来源

1. **用户输入的原话**（可以改写措辞，不可以改数值）
2. **脚本按公式计算的结果**（必须标注「按你给的数算，公司带宽以实际为准」）

其他来源一律标 `[待补充]`，或者用无数字降级法改写。

## 五、输出前自检清单（11 条，逐条打勾）

- [ ] **1. 数字出处**：邮件里每个数字都能追到用户原话或脚本输出，没有我编的？
- [ ] **2. 主由头强度**：主由头是职责扩展 / 增量贡献 / 关键人才保留 / 带宽校准之一，不是市场对标、不是年限？
- [ ] **3. 顺序正确**：预沟通脚本在正式邮件之前，且明确说了「先约非正式沟通」？
- [ ] **4. 禁用句式**：没有卖惨、比较、威胁、年限四类句式？
- [ ] **5. 敏感变量**：年龄、性别、婚育、家庭负担没有进入任何对外文本？
- [ ] **6. 涨幅匹配**：涨幅在该由头的经验区间内，或已说明为什么超出？
- [ ] **7. 企业类型**：做了企业类型适配，没做则按流程严格型保守输出？
- [ ] **8. 结构收益**：按兑现确定性排序，高确定性在前，且每个科目配了书面化动作？
- [ ] **9. 退路完整**：有被拒后的 30/60/90 日历，且 D+3 确认邮件写了？
- [ ] **10. 形容词测试**：邮件删掉所有形容词后，每句仍成立？
- [ ] **11. 承诺边界**：没有出现「这样谈能批」「通过率很高」这类结果承诺？

**第 10 条是全套里最锋利的检查**。「我很努力地推动了项目」删掉形容词变成「我推动了项目」——还成立，说明有事实。「我为团队做出了巨大贡献」删掉形容词变成「我为团队做出了贡献」——空洞，说明这句是凑数的。

## 六、什么时候该劝用户别谈

这是最容易被忽略、但对用户最负责的一条。

| 情况 | 判断 | 该说的话 |
|---|---|---|
| 弹药为零（既无增量也无职责变化） | 时机不成立 | 「先做出一件可核实的事，下个窗口再谈。现在硬写会消耗一次机会」 |
| 负面信号命中两个以上 | 需等待 | 「现在提大概率被拒，且会影响半年后的复评」 |
| BATNA 极弱 + 期望涨幅远超由头强度 | 高风险 | 「这个组合下被拒概率高，且被拒后你在谈判里的位置会更低」 |
| 公司已明确冻结 | 不成立 | 「转结构收益与复谈日历，不再写加薪邮件」 |
| 用户情绪化，只想发泄 | 不适用 | 接住情绪，问是否要方案，不硬推六件套 |

**说「别谈」不是失职，是这套东西最有价值的部分。** 大部分加薪失败不是因为话术不好，是因为在不该谈的时候谈了。
