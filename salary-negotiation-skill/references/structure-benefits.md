# 结构收益：底薪谈不动时的第二战场

底薪受阻是常态，不是失败。**真正的失败是在底薪被否之后，空手离场。**

但结构收益有个陷阱：它是最容易被「画饼」的地方。原提示词把现金位移、期权、发展授权并列成四类，这是危险的并列——期权和发展授权在雇员侧的兑现概率，远低于奖金系数和津贴。并列等于给了 HR 一张「用低成本科目换高成本诉求」的菜单。

所以这份文件的第一原则是：**按兑现确定性排序，高确定性放前面。**

---

## 一、兑现确定性分级

| 确定性 | 科目 | 判据 | 谈的难度 |
|---|---|---|---|
| **高** | 奖金系数、绩效评优优先级、项目奖金权重、岗位/带教/通讯交通补贴 | 当期可见，写进制度或考核表即兑现 | 低 |
| **中高** | 项目分红、明确的季度/年度奖励池 | 有分配规则，但依赖业绩达成 | 中 |
| **中** | 补充医疗升级、弹性工作、远程天数、家属保障 | 有预算即兑现，无预算即空 | 中 |
| **低** | 期权、虚拟股、利润分享 | 依赖退出机制与估值，3 年内难兑现 | 高（公司爱给） |
| **最低** | 发展授权、储备干部资格、核心项目主导权、高管导师 | 无书面即无约束，口头等于零 | 最低（公司最爱给） |

**读这张表的方式**：确定性越低的科目，公司给起来越爽快。所以当对方主动提「期权」「储备干部」「核心项目交给你」时，你要意识到——**他正在用低成本科目回应你的高成本诉求。**

这不代表这些科目没价值，代表它们需要**书面化**才能变成价值。

---

## 二、四类科目明细

### 第 1 类 · 现金结构内位移（优先谈）

不动底薪，动底薪之外的钱。这是最容易谈成的一类，因为它不改变薪酬体系，只改变分配比例。

| 科目 | 怎么提 | 大概幅度 |
|---|---|---|
| 奖金系数 | 「我的绩效系数能不能调到 X 档」 | 常见 0.1—0.3 个系数，折年化 3%—10% |
| 绩效评优优先级 | 「评优的时候能不能优先考虑」 | 影响年终系数，1—2 个月薪资 |
| 项目奖金权重 | 「后续项目的奖金分配权重能不能提高」 | 按项目，5%—15% |
| 岗位/带教/通讯交通补贴 | 「能不能增设/提高 X 补贴」 | 每月几百到几千 |

**为什么这类最容易成**：它走的是「制度内调整」，不需要特批，直属领导往往自己就能定。而且对公司来说，浮动部分不增加固定人力成本，财报上更友好。

### 第 2 类 · 浮动与长期激励（要问清规则）

| 科目 | 必问的三个问题 |
|---|---|
| 项目分红 | 分红池怎么算？什么时候分？谁能决定分给谁？ |
| 虚拟股 / 期权 | 授予价？行权条件？离职怎么处理？有没有回购机制？ |
| 利润分享 | 按什么口径算利润？分几年？有没有上限？ |

**纪律**：这三个问题问不出来，这个科目就是零。**不要因为对方说「会给你期权」就当作谈成了**——没有授予价和行权条件的期权，是一张没有金额的纸。

### 第 3 类 · 发展授权与角色升级（必须书面化）

| 科目 | 书面化动作 |
|---|---|
| 核心项目主导权 | 写进项目立项书或邮件确认「由 X 负责」 |
| 带团队 / 带教 | 写进 JD 或组织架构，明确汇报关系 |
| 跨部门轮岗 | 写进邮件，明确时间与接收方 |
| 储备干部资格 | 要书面通知或名单，不要口头许诺 |
| 高管导师 | 要固定的月度时间，否则三个月后自动消失 |

**这一类的真相**：它的价值完全取决于「能不能变成下一份简历上的一行字」。如果拿不到书面，它的价值等于一次口头表扬。

### 第 4 类 · 福利与生活场景（实用，但别当主菜）

补充医疗升级、弹性工作、远程天数、家属保障、教育/赡养津贴。

**用途**：这类科目的好处是**对公司的现金成本低、对你的实际体验提升明显**，适合作为「底薪谈不动、但我不想空手走」的收尾项。不要用它替代现金诉求，它的量级不够。

## 三、转换话术（一句，背下来）

> 「理解基本工资的预算约束。如果底薪暂时动不了，是否可以在奖金系数、项目分配或带教津贴上做结构性安排？这样对公司成本压力更小，对我也有实际激励。」

**这句话的结构值得拆开看**：
1. 先接受前提（理解预算约束）——不否定对方，不制造对立
2. 再给三个具体选项——不给开放问题（「那能给我什么」），给选择题
3. 最后说清双赢逻辑——「对公司成本压力更小」是真的，浮动部分不占固定人力成本

**不要说**：「那你们总得补偿我点什么吧」——这句话把结构收益变成了施舍，对方只会给最便宜的那个。

---

## 四、缺口补位法（用定价结果驱动，不是随便要）

结构收益不是「能要多少要多少」，而是**按缺口补**。

定价脚本会算出 `缺口 = Target − Walk-away`。这个数就是结构收益要补的额度。

```
例：Target = 23000，Walk = 15000 → 缺口 = 8000/月 = 9.6 万/年
```

9.6 万/年的缺口，可以这样拆：
- 奖金系数从 1.0 提到 1.3 → 约 3 个月薪资浮动 → 覆盖 40%
- 项目奖金权重提高 → 覆盖 30%
- 带教津贴 → 覆盖 15%
- 剩下的接受，换 D+60 的复评承诺

**这样谈的好处**：你不是在「要东西」，你是在「按缺口配平」。对方看到的是一个可核算的方案，不是一个情绪诉求。

## 五、书面化动作（每条都要配一句）

任何非现金科目，谈成之后必须配一个书面化动作，否则不算谈成。

| 科目类型 | 书面化动作 | 话术 |
|---|---|---|
| 系数 / 评优 | 写进考核表或绩效目标书 | 「这个我理解是写进今年考核表对吧？我回头按这个准备。」 |
| 项目奖金 | 邮件确认分配规则 | 「方便的话我把分配规则整理一下发您确认，免得后面理解不一致。」 |
| 期权 / 虚拟股 | 要授予协议文本 | 「协议文本大概什么时候能给到？我想先看看条款。」 |
| 带团队 / 主导权 | 写进 JD 或组织架构 | 「这个调整会体现在 JD 里吗？我想确认一下对外口径。」 |
| 轮岗 / 导师 | 邮件确认时间与对象 | 「我把时间定下来发您，免得两边都忙忘了。」 |

**最后一句通用兜底**：「我把今天聊到的整理一下发您确认，如果有理解偏差您指正。」——这句话在任何场景都能用，而且不会引起反感，因为它给了对方纠正权。

---

## 六、一条底线

结构收益是**第二战场，不是替代品**。

如果底薪缺口超过 30%，且公司连续两个窗口只给结构收益不给现金，那说明的不是「公司在想办法补偿你」，而是「公司不打算为这个岗位付更多固定成本」。

这时候该做的不是继续要结构收益，是重估 BATNA（见 `references/guardrails.md`）。**结构收益能补缺口，补不了定位。**
